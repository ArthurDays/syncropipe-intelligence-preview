# Syncropipe Intelligence — Preview

Apresentação institucional e protótipos de interfaces para software sob medida, automação e integração de dados.

O repositório reúne uma página estática com serviços, exemplos conceituais de landing pages e demonstrações visuais de atendimento e fluxos operacionais.

## Escopo

- Apresentação de soluções digitais e canais de contato.
- Exemplos de interfaces para diferentes segmentos.
- Simulação visual de atendimento com IA.
- Protótipos para explorar jornadas e organização das informações.

**As demonstrações visuais não comprovam integrações ativas com IA, CRM, WhatsApp ou outras plataformas.** A página identifica exemplos conceituais e simulações; este repositório não deve ser apresentado como evidência de resultados de clientes.

## Tecnologias

HTML, CSS e JavaScript, com imagens e ícones locais. A página principal pode ser servida como conteúdo estático.

## Executar localmente

Com Python 3 instalado:

```bash
git clone https://github.com/ArthurDays/syncropipe-intelligence-preview.git
cd syncropipe-intelligence-preview
python -m http.server 8000 --bind 127.0.0.1
```

Abra [http://127.0.0.1:8000](http://127.0.0.1:8000).

Alguns links e conteúdos incorporados apontam para endereços externos e podem exigir conexão. Revise os destinos dos botões de contato antes de testar envios.

## Verificação manual

- Conferir navegação e leitura em celular e desktop.
- Verificar botões, âncoras, carregamento de imagens e conteúdo incorporado.
- Percorrer as interfaces por teclado e conferir foco visível.

- Medir acessibilidade e desempenho antes de publicar alegações sobre essas qualidades.
